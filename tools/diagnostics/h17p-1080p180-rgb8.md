# H17P external 1080p180 RGB8 diagnostic

This is a default-off source diagnostic, not a production mode-policy change.
The boot/load-time `experimental_h17p_1080p180_rgb8` appledrm parameter only
reaches the experimental external H17P TimingElements parser. Normal parsing,
other firmware profiles, internal panels and existing valid selections remain
unchanged. The parser resets the opt-in for every new property blob.

Only an otherwise rejected firmware timing can be exposed: explicit nonvirtual,
progressive 1920x1080 with totals 2080x1106 and the captured fixed-point
rate 11796583/65536 Hz (approximately 180.00157 Hz), with no pixel repetition
and known sync polarities. Its own advertised ColorModes must contain a scored nonvirtual
8-bit full-range SDR RGB candidate in sRGB, BT.709 or Default RGB. The exception
applies only to UnsafeColorElementIDs; DSCRequiredColorElementIDs, malformed
restriction lists, parser bounds and normal link/modeset checks still refuse.
No global color ID is combined with a different timing. The timing fields and
firmware IDs are kept as received, without changing link registers or blanking.

An added diagnostic timing is never marked preferred and cannot supply the
firmware-derived EDID preferred timing. This does not stop a compositor from
restoring an explicitly saved mode, so use a separately reviewed controlled
session and record the actual selection. Safe modes are not converted to RGB8.

Before enabling on hardware, capture the current monitor/dock/physical route's
TimingElements and confirm the local candidate, DSC list, full range, depth,
clock and timing. A capture from a different dock/port is not evidence for the
current route. The existing short-vblank firmware warning is not bypassed or
reinterpreted; a successful advertisement alone proves no transport safety.
Physical output, sustained presentation, errors and return to the baseline mode
require separate qualification. Do not infer production safety or relax other
guards from this diagnostic.

`test-apple-external-sdr.py` exercises the production parser with the option off
and on, malformed/DSC/range/depth/virtual/scope negatives, reversed dictionary
order, timing-local candidates, and non-preferred diagnostic mode handling.
Fixtures are independently generated protocol dictionaries with no private
monitor payloads or identity fields.
